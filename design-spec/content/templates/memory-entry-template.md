# Memory Entry Template

## Purpose
Standardize how durable preferences, facts, decisions, people, and
learnings are recorded in the memory files.

## When to Use
Whenever a memory entry is proposed (each proposal is approved
individually; sensitive entries always require explicit approval).

## Template
```markdown
### YYYY-MM-DD — [Entry Title]

**Type:**
**Summary:**
**Source:**
**Confidence:** [high | medium | low]
**Owner:**
**Review Date:**
**Notes:**
```

## Completion Checklist
- Entry placed in the correct memory file per governance.md Memory
  Boundaries.
- Durable and useful — not a one-time fact or raw note.

## Notes
Stale entries are marked, superseded, or corrected with a new entry — never
silently deleted.
