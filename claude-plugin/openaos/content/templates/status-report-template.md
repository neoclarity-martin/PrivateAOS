# Status Report Template

## Purpose
Standard format for status summaries, including the daily startup brief.

## When to Use
Daily startup, weekly review, or any "where do things stand?" request.

## Template
```markdown
## Priorities
## Active Projects
## Pending Approvals
## Recent Decisions
## Next Actions
## Processed Inbox
```

## Completion Checklist
- Every section present, in order; empty sections say "None".
- Pending Approvals lists each waiting `Proceed` explicitly.

## Notes
For the startup brief, the Processed Inbox section uses the four brief
categories: Items processed; Items still unresolved; Where items were
promoted to; Items requiring user approval.
