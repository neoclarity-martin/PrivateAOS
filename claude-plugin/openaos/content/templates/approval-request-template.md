# Approval Request Template

## Purpose
Standardize how workflows ask you to approve Level 2 actions requiring
`Proceed`.

## When to Use
Before any approval-required action (see governance.md Permission Model).

## Template
```markdown
**Proposed Action:**
**Affected Files:**
**Reason:**
**Consequence:**
**Approval:** type exactly `Proceed` to authorize
```

## Completion Checklist
- All five fields filled; affected files listed individually.
- The request states that anything short of the exact word is a hold.

## Notes
These are the five elements of the governance Proceed Gate, as labeled
fields.
